# Перенос текстовых аннотаций при выравнивании BPMN

## Причина

На вашей схеме все семь аннотаций остались на исходных координатах, хотя связанные задачи переместились. Планировщик учитывает `TextAnnotation` как препятствие, но связь `Association` не используется для расчёта позиции аннотации. Четыре аннотации оформлены на уровне коллаборации, хотя их задачи находятся внутри пулов. Поэтому искать связи нужно по всей диаграмме.

## Изменения

- Применить общее правило к командам **«Автовыровнять»** и **«Выровнять выделение»**. Находить `Association` в обоих направлениях. При выравнивании выделения переносить также невыделенную аннотацию, если её опорный блок перемещается. При нескольких связях брать ближайший по исходным координатам блок из перемещаемых, при равенстве выбирать по BPMN ID. Сохранять все связи. Аннотации без связей остаются на месте относительно своего контейнера, если пользователь явно их не выделил.
- Сначала рассчитать новые позиции блоков и пулов, затем применить к аннотации смещение её опорного блока. Если это место занято, искать ближайшую свободную позицию с учётом размеров аннотации, фигур, видимых подписей, потоков и уже размещённых аннотаций. Сохранять принадлежность пулу, дорожке или подпроцессу по исходной структуре и геометрии. Аннотация уровня коллаборации, которая визуально лежала внутри пула своего блока, должна остаться внутри после переноса.
- Если внутри контейнера места нет, добавить полосу снизу для горизонтальной раскладки или справа для вертикальной. Для полного выравнивания перерассчитать затронутые границы дорожек и пулов и проложить потоки заново. Для выделения расширять только явно выбранный контейнер и только если соседние фигуры могут остаться на месте. Если допустимую раскладку получить не удалось, отменить операцию целиком и указать причину в статусе.
- Проверить итоговую геометрию до применения. Перестроить затронутые ассоциации так, чтобы их концы прилегали к актуальным границам фигур, а линии обходили посторонние фигуры. Применить координаты, размеры и маршруты одной командой через существующий стек отмены. Формат BPMN и интерфейс команд сохраняются.

## Проверка

- Добавить регрессии для точного переноса со смещением блока, выбора ближайшего свободного места, нескольких аннотаций рядом, обратной и множественной ассоциации, а также аннотации коллаборации, связанной с задачей внутри пула.
- Проверить расширение горизонтальных и вертикальных дорожек и вложенного подпроцесса. Для выравнивания выделения проверить успешный перенос невыделенной аннотации, сохранение позиций соседних фигур и отказ без частичных изменений, если расширение недопустимо.
- В браузере открыть [исходную схему](</Users/korso/Downloads/diagram (4) (1).bpmn>), выполнить полное выравнивание и экспортировать результат. Сравнить BPMN-координаты и маршруты всех семи аннотаций, проверить отсутствие наложений, повторный запуск без изменений и восстановление геометрии через Undo и Redo. Отдельно проверить выравнивание выделения. Запустить `npm test` и `npm run build` на Node.js 24.

В рабочем дереве уже есть две незавершённые правки из предыдущей попытки. При реализации проверить и доработать поиск свободного места и передачу типа связи в планировщик. Сейчас эти правки ещё не подключены к выравниванию.
