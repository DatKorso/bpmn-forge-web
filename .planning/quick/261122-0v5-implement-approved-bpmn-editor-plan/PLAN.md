# Выравнивание участка, свойства BPMN и единый интерфейс

## Результат

В BPMN Forge можно выровнять одну область или несколько выделенных фигур, сохранив геометрию остальной схемы. Правая панель позволяет редактировать стандартные свойства BPMN 2.0. Панель действий, свойства, палитра и диалоги оформлены в едином компактном светлом стиле.

## Автовыравнивание выделения

- Добавить рядом с существующим «Автовыровнять» отдельное действие «Выровнять выделение». Оба действия используют текущие настройки минимальных отступов. Кнопка для выделения недоступна, пока выделение не подходит. Причину можно прочитать с клавиатуры и экранного диктора.
- Поддержать два варианта выделения. Один пул, дорожка или раскрытый подпроцесс выравнивает фигуры внутри себя. Две и более фигуры можно выровнять вместе, если они принадлежат одному процессу или подпроцессу, в том числе на разных дорожках. Смешанное выделение контейнера и отдельных фигур, а также выделение из разных процессов или подпроцессов недоступно. Вложенный подпроцесс перемещается целиком с содержимым. Чтобы выровнять его содержимое отдельно, нужно выбрать сам подпроцесс.
- Использовать существующие алгоритмы раскладки и трассировки. В режиме выделения зафиксировать размеры и положение контейнеров, принадлежность фигур к дорожкам и координаты соседних фигур. Подписи и граничные события следуют за своими фигурами. Перестраивать только связи перемещённых фигур, включая связи с неподвижными элементами. Остальные маршруты сохраняются.
- Сначала рассчитать весь результат. Если обычная и компактная раскладки не помещаются или затронутые потоки управления не удаётся провести в обход фигур, оставить участок без изменений и показать причину. Успешное выравнивание отменяется и повторяется одним действием.

## Свойства и BPMN XML

- Добавить сворачиваемую правую панель «Свойства». Для одного элемента показывать его тип, ID и применимые поля. При пустом выделении предложить выбрать элемент, при множественном показать количество выбранных элементов. При выборе подписи открывать свойства элемента, которому она принадлежит.
- Дать редактировать название и записи описания у поддерживающих их элементов. Для подходящих потоков управления добавить текст условия и управление веткой по умолчанию. Смена ветки обновляет ссылку `default` у исходного элемента. Чтобы назначить ветку с условием веткой по умолчанию, сначала нужно явно очистить условие. [Спецификация BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/PDF)
- Записывать значения через стек команд `bpmn-js` в стандартные поля `name`, `documentation`, `conditionExpression` и `default`. Фиксировать текстовые правки при выходе из поля, а выбор ветки — сразу. Сохранять язык и другие атрибуты существующего выражения при редактировании его текста. Выражения хранить как текст. Скачанный файл проверять повторным открытием в Forge. Проверка в сторонних редакторах за рамками приёмки.

## Единый интерфейс

- Сохранить светлые поверхности и синий акцент. Использовать общие CSS-переменные для цветов, отступов, скруглений, размеров контролов и состояний фокуса. Применить их к верхней панели, палитре, контекстным меню, свойствам, футеру и диалогам.
- Сгруппировать действия по работе с файлом, истории и выравниванию. На широком экране разместить свойства справа от полотна. На узком открывать их по кнопке поверх полотна. При изменении размеров рабочей области обновлять размер холста с сохранением текущего масштаба. Оформление интерфейса не должно менять цвета фигур в BPMN-файле.

## Приёмка

- На схемах с горизонтальными и вертикальными дорожками проверить выравнивание дорожки, пула, раскрытого подпроцесса и ручного выделения на нескольких дорожках. Сравнить координаты соседних фигур, границы контейнеров, принадлежность к дорожкам и маршруты незатронутых связей. Проверить отказ при нехватке места, повторный запуск, отмену и повтор.
- В браузере изменить название, многострочное описание, условие и ветку по умолчанию. Проверить обновление подписей и маркеров, затем скачать BPMN, проверить ссылки и значения в XML и открыть его снова в Forge.
- Проверить редактор на широком и узком экранах, управление с клавиатуры и отсутствие срабатывания горячих клавиш полотна при вводе текста. Запустить `npm test` и `npm run build` на Node.js 24.
