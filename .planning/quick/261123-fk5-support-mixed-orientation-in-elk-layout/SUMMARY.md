# Support mixed orientation in ELK layout

Реализован смешанный режим ELK β для проверочной сборки. Каждый пул сохраняет направление процесса, общая ось ряда определяется по большинству, а просмотр и применение сохраняют атомарную историю. Дорожки с несовпадающей ориентацией отклоняются с указанием ID.

Геометрическая приёмка сохранила старые отпечатки и 306 прогонов, добавила по 30 прогонов на ось и прошла с полными профилями после экспорта и открытия. Зафиксированы код `c68e7c1`, [решение о выпуске](../../elk-mixed-orientation/DECISION.md) и [все замеры](../../elk-mixed-orientation/BENCHMARK.jsonl).

После оптимизации медианы Chromium на 4×50 составили 2 132 мс по Y и 1 482 мс по X. Смешанный режим остаётся в проверочной сборке. Порог пересмотра Web Worker достигнут на обеих осях.
