## Gate fixed before the first run

Stop on `tight-pool` or `vertical-pool` if an ELK-straight main flow loses a free straight passage, if the final routes add crossings to a diagram with zero in ELK and the current planner, or if any run fails or violates R1–R4. Diagnose alignment loss separately from a routing detour. Measure after ELK, after packing/snapping, and after final routing. Repair packing or routing and rerun before beginning stage 2.
