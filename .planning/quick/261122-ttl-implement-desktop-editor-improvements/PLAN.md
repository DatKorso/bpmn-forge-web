# Улучшение настольного редактора BPMN Forge

## Цель

Защитить несохранённые правки, сделать результат действий заметным и упростить работу с полотном мышью и клавиатурой. Реализовать весь согласованный объём в три этапа. Целевой сценарий — настольный браузер с мышью и клавиатурой. Основные размеры для приёмки — 1024×600, 1280×800 и 1440×900.

## Этап 1. Защита правок и сообщения об ошибках

- Показывать рядом с именем файла «Есть несохранённые изменения». Отслеживать состояние по событиям стека команд. Загруженная схема и версия перед успешным запуском скачивания становятся контрольными точками. Undo и Redo корректно возвращают индикатор при переходе через контрольную точку. Новая правка после Undo образует новую ветку истории.
- Для «Создать схему» и «Открыть BPMN» использовать один диалог подтверждения. При открытии показывать его после выбора файла. Действия — «Скачать BPMN и продолжить», «Продолжить без скачивания», «Отмена». По умолчанию фокус на «Отмена». Escape возвращает пользователя к текущей схеме. При сбое экспорта текущий документ и история сохраняются. Для перезагрузки и закрытия вкладки с правками использовать системное предупреждение браузера.
- Ошибки импорта и экспорта показывать текстом под панелью действий и сохранять в диалоге «Сообщения редактора». Сообщение доступно экранному диктору, закрывается пользователем и исчезает после успешного повтора той же операции. Импорт по-прежнему заменяет текущую схему только после успешной загрузки новой.

## Этап 2. Палитра и управление полотном

- Сделать палитру одной остановкой Tab. Стрелки перемещают фокус, Enter и пробел активируют пункт, Tab выводит из палитры. Сохранить русские доступные названия и существующие действия мышью. Учесть свёрнутое состояние палитры в низком окне.
- Для пунктов создания включать режим размещения. Маркер появляется в центре видимой области, стрелки перемещают его с шагом сетки, Enter размещает фигуру, Escape отменяет действие и возвращает фокус в палитру. Использовать общие фабрики фигур для мыши и клавиатуры и правила `bpmn-js` для проверки места размещения. Создание выполняется одной командой отмены. После создания название можно ввести с клавиатуры через штатное редактирование подписи.
- Закрепить свойства сбоку с разделителем в 1 px и прокруткой внутри панели. При открытии сдвигать вид, если выделение оказалось за краем полотна. Добавить кнопки «Уменьшить», «Увеличить» и «Показать всю схему». Вписывание при импорте и по кнопке учитывает место, занятое палитрой и свойствами. После выравнивания масштаб сохраняется, а полный обзор восстанавливается одним нажатием.

## Этап 3. Выравнивание и визуальная полировка

- Подписать действия «Выровнять схему» и «Выровнять выделение». На пустом полотне отключить выравнивание и дать заметное действие «Открыть BPMN». Сохранить подсказку о том, какое выделение подходит для операции.
- В отступах поставить минимум и максимум рядом для каждой оси, пояснить значение пустого максимума и показывать ошибку под полем. Сохранить перевод фокуса к первому некорректному значению.
- В нижней строке показывать короткий результат выравнивания целиком. Счётчики и причины пропуска оставить в «Подробнее». Сохранить текущую палитру и сетку полотна, уменьшить тени у диалогов и всплывающих панелей.

## Проверка и выпуск

- Добавить Playwright-проверки для защиты правок при создании и открытии схемы, Undo и Redo вокруг контрольной точки, отказа от замены, сбоя экспорта и видимой ошибки импорта.
- Проверить клавиатурный сценарий от пустой схемы до создания, именования и отмены задачи. На трёх целевых размерах проверить свойства, вписывание тестового пула, читаемость сводки и доступность палитры в низком окне.
- Выпустить этапы через обычные PR с `npm test`, `npm run build` и `npm run test:e2e` на Node.js 24. Сохранение остаётся файловым. Клавиатурный объём охватывает палитру, создание и именование фигур. Адаптивная переработка для телефонов остаётся за рамками плана.
