# Приёмка смешанных пулов ELK β

Штатный выпуск смешанного режима отложен. Компактные схемы проходят секундный критерий. После одного цикла оптимизации полные профили 4×50 в Chromium занимают 2 132 мс по Y и 1 482 мс по X по тёплой медиане. Публичная сборка продолжает предлагать «Выровнять схему» при разных ориентациях. Смешанный режим проверяется в сборке `graph-mixed-verification`. Решение об ограниченной β и её бюджете задержки остаётся за владельцем.

Порог пересмотра Web Worker достигнут в пяти из пяти тёплых запусков на каждой оси при 4×50. Следующий отдельный эксперимент для отзывчивости — выполнить планирование по снимку вне главного потока и оставить подтверждение, проверку актуальности и применение команды в редакторе. Секундный критерий задержки до предпросмотра подлежит отдельной проверке.

## Геометрия

- Проверены выбор обеих осей, равенство 1+1 и 2+2, порядок по исходным центрам, совпадающие центры, касание при нулевом отступе и сохранение дробных координат и размеров. Рамки и SequenceFlow изолированных пулов совпадают с их геометрией в ряду после переноса. Пулы без DI исключены.
- Сохранены прежние отпечатки обоих движков и 306 прогонов. Добавлено 30 прогонов на каждую ось с амплитудами 15, 40 и 120. Проверяются рамки, SequenceFlow, заметка, внешние пути и подписи при изменении DI, ID, порядка массивов и исходных точек связей. R1–R6 проверяются скриптами качества и прототипа. R7 проверяется в Chromium.
- У компактных профилей ноль пересечений и ноль общих сегментов между внешними связями и с SequenceFlow. Прямые встречные сообщения между участниками получают по две точки. Для вынужденного обхода закреплён пяти-точечный эталон для каждой оси с проверкой вложенных рамок, полосы заголовка, промежуточного пула и круглого порта граничного события.
- Chromium проверяет полосы заголовков обоих направлений, дорожки, заметку по дельте опоры, подпись именованного сообщения при отсутствии исходного BPMNLabel, отмену, один undo/redo и флаги DI после экспорта. На полных профилях повтор пуст после применения и после экспорта и открытия. Отказ при несогласованной дорожке адресный. Поздние отказы маршрутизации и подписи не возвращают частичный план.

## Замеры

Apple M1 Pro, Node 24.22.3, Chromium 159.0.8154.6. Один холодный и пять тёплых запусков на профиль. Node измеряет расчёт после чтения BPMN. Chromium измеряет от клика до предпросмотра или отказа и дополнительно записывает Long Tasks. Полная нагрузка имеет seed 42, 200 узлов, 216 SequenceFlow, 24 MessageFlow с исходными парами, восемь заметок с Association и четыре раскрытых подпроцесса. ## Воспроизведение

`npm test`, `npm run build`, `npm run test:e2e`, `node scripts/graph-layout-quality.mjs --quality --check-routes`, `node scripts/graph-layout-placement.mjs`, `node scripts/graph-layout-prototype.mjs` и `node scripts/benchmark-graph-layout.mjs`.

Для смешанного режима сначала выполните `npm run build -- --mode graph-mixed-verification`, затем запустите Playwright с `BPMN_GRAPH_MIXED_VERIFICATION=1`. Для замера добавьте `BPMN_GRAPH_BENCHMARK=1` и аргументы `-- e2e/graph-layout-benchmark.spec.js --workers=1`. Для масштабной серии задайте `BPMN_GRAPH_BENCHMARK_SIZE` и фильтр `--grep 'the mixed-'`. В Node можно передать имя профиля и размер, например `node scripts/benchmark-graph-layout.mjs mixed-y 20`.
